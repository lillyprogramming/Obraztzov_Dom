# Obraztzov_Dom
Obrazov Dom is a web application designed to help households organize tasks, communicate more easily, and work together towards creating their ideal home.
The app allows household members to manage responsibilities, improve coordination, and stay motivated through a shared vision of their “Dream Home.” It combines practical organization tools with a more personal approach to household management.

I made this web application in 2024 for an Information Technology olympiad.

## Tech Stack

- Frontend: `React`, `JavaScript`, `HTML`, `CSS`, `Sass`, `JSON`
- Backend: `Node.js`, `Express`
- Database: `MySQL`

## How to Run the Project

First split the terminal into two

In the first one, write:
```bash
cd client
npm install
npm run start
```

In the second one, write:
```bash
cd api
npm install
npm run start
```
